# G6 — Phase as Address

G6 is a post-v0 extension. It does **not** alter the frozen G0–G5 thresholds or receipt.

## Question

Can relative phase itself select between two learned continuations when the two candidate inputs have equal energy and there is no unit-specific context signal?

The canonical branch pair remains:

- `A B C D E F G`
- `A B C H I J K`

For G6, the learned connections from the shared prefix (`A/B/C`) into the branch-specific units are lesioned identically in every arm. Two equal upstream test volleys are then delivered to `D` and `H` in opposite halves of one 20 ms local cycle. Downstream branch weights remain learned.

The only request-selecting variable in the two phase arms is the phase of a **global** inhibitory gate:

- phase-D: D volley open, H volley inhibited;
- phase-H: D volley inhibited, H volley open.

Both phase arms contain the same total inhibitory area. A matched tonic arm uses that same mean inhibition but has no phase address. No multiplicative or additive context vector is used.

## Controls and invariants

For every seed:

1. pre-decision internal state must be exactly identical across phase-D and phase-H;
2. D and H candidate volleys must have equal energy;
3. phase-D and phase-H must have equal mean inhibitory area;
4. tonic inhibition must have that same mean inhibitory area;
5. all context-gain arrays must remain identity;
6. the same tonic trace is scored against both mutually exclusive requests, so it cannot encode both;
7. 16 random phases are paired with independent random D/H requests as a chance control.

Pilot seeds `0–3` were used only as an assay smoke test. The canonical rule below is fixed before running canonical seeds `100–111`.

## Frozen canonical rule

G6 passes only if:

- at least **10/12** canonical seeds satisfy the core contract:
  - phase-D selects D;
  - phase-H selects H;
  - all five invariants hold;
  - tonic cannot encode both requested branches;
- pooled random-phase request accuracy over `12 × 16 = 192` trials is within **[0.35, 0.65]**.

No threshold is changed after canonical results are seen.
